# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [1.0.6] - 2026-09-20
### Added
- Copying of links in tweets
- Copying of images in tweets
- Copying of @handles and @mentions in tweets

## [1.0.5] - 2025-03-21
### Added
- Support for copying emojis from tweets.
- Fallback to `document.execCommand` for older browsers.

### Fixed
- Bug where the copy button did not appear on some tweet layouts.
- Deprecation warnings related to `document.execCommand`.

## [1.0.4] - 2024-06-12
### Added
- Match x.com in scripts.

### Fixed
- Bugs.

## [1.0.3] - 2022-05-29
### Added
- Added rounded corners to icons.

### Fixed
- Bugs.

## [1.0.2] - 2022-05-28
### Added
- Added rounded corners to icons.

### Fixed
- Bugs.

## [1.0.1] - 2021-08-20
### Added
- Add authorName and authorHandle to copied text.

### Fixed
- Bugs.

## [1.0.0] - 2021-07-09
### Added
- Initial version of the Firefox add-on.
